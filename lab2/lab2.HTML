projects

Dungeon BSP Generator – Procedural Roguelike Engine

Designed and built a procedural dungeon generator from scratch using a Binary Space Partitioning (BSP) algorithm in C++ and Raylib to produce interconnected levels, featuring a custom STL-free dynamic array, recursive BSP tree logic, and a full game loop with collision detection and fog-of-war.

Tiny Language Compiler

Developed a compiler for the TINY programming language from scratch using C++, implementing all major compilation phases including lexical analysis, parsing, semantic analysis, and code generation

MIPS Processor Design

Designed and simulated a full MIPS CPU in VHDL supporting R-type, I-type, and J-type instructions, including a custom register file, 32-bit ALU, control unit, datapath, and memory modules.
